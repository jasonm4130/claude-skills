## What wave 1 produced

Thirteen finders (E1..E6 evidence, R1..R7 research), each adversarially verified. Per finder, `REVIEW/wave1/<label>.json` holds `findings[]` (title, claim, evidence, classification, confidence, actionable) and `verification` = `{verdicts[]: {title, verdict: confirmed|weakened|refuted, reason, corrected_claim}, missed}`. `REVIEW/wave1/digest.md` is a compressed view of all thirteen.

Rules for using them:
- A `refuted` finding is dead unless its `corrected_claim` is non-empty, in which case the corrected claim replaces it at reduced confidence.
- A `weakened` finding is used only in its `corrected_claim` form.
- `confirmed` findings are used as written, with any verifier correction applied.
- The verifier's `missed` text contains new findings; they are candidates, not established. Include one only if it cites evidence that can be checked in the pack.
- Numbers: every dollar figure from E1 is inflated 2.2 to 2.4x because the index summed usage once per content block; the corrected totals are local period ~$2,510, archive ~$10,677, ~$175-179 per active day at list price on a Max plan (opportunity cost, not a bill). Do not quote any uncorrected dollar figure.
