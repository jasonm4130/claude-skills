# Gates Configuration and Nightshift Edges Implementation Plan

**Goal:** a repo can switch individual gates off with one committed file; the compiled guards and their fallbacks agree on it; and the four rough edges the first Nightshift week exposed (guard over-match, unadoptable copies, an untested morning, no evals) are closed.
**Architecture:** `.claude/gates.json` at the repo root, found by walking up from the hook payload's `cwd`, read by the Go binary and by every `.mjs` guard through one shared function each; the differential test proves both agree. Nightshift changes land in the plugin's templates and scripts, never in this repo's `loop/` or `.claude/` copies (a human runs `init.mjs --update` afterwards).
**Tech Stack:** Go 1.27.1 (`go` is on PATH via mise), `lipo`, stdlib `.mjs`, Node 24 `node --test`, `scripts/bump-plugin.mjs`.

## Global Constraints
- Any change under `plugins/<name>/` outside `README.md`, `CLAUDE.md`, `tests/` MUST be followed by `node scripts/bump-plugin.mjs <name> patch` (minor where the task says) before the commit.
- `bash scripts/check` must end with `CHECK OK` before every commit. Never delete a test.
- Every task that edits `plugins/gates/go/*.go` MUST, before committing: `(cd plugins/gates/go && go vet ./... && go test ./...)` → PASS, then rebuild exactly as `plugins/gates/go/README.md` "Rebuilding" says (`GOOS=darwin GOARCH=arm64 go build -buildvcs=false -ldflags="-s -w" -trimpath -o /tmp/cc-arm64 .`, the same for `amd64`, `lipo -create -output ../bin/ccguard /tmp/cc-arm64 /tmp/cc-amd64`), commit `plugins/gates/bin/ccguard` in the same commit, and run `node --test scripts/ccguard-differential.test.mjs` → PASS. CI rebuilds and compares the binary byte-for-byte.
- Do not edit `.github/`, `.claude/`, `loop/`, or `scripts/` unless the task names the file. `plugins/gates/hooks/hooks.json` and `plugins/nightshift/templates/**` are plugin payload and are in scope.
- Commit messages say why and end with the line `Claude-Session: nightshift`.
