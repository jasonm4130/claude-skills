The rulebook ingestion pipeline embeds text chunks in batches by calling an embeddings API, previously capped at a fixed number of strings per call. The embeddings API also enforces a maximum total token count per call, and chunks that include a prepended contextual blurb can push a fixed-size batch over that token ceiling even though it stays under the string-count cap. Change the batching logic to accumulate chunks into a batch until either the string-count cap or a token-budget cap is reached, flushing and starting a new batch whenever either limit would be exceeded, and make sure any partial batch at the end still gets sent.
