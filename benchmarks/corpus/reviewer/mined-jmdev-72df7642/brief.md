Blog posts sometimes link to other posts internally, but a linked post might still be a draft or scheduled for a future date at the time the site builds. Add a build-time markdown transform that walks each document's link nodes, and for any link pointing at `/blog/<slug>`, checks whether that target post is currently published using the same "not draft and not future-dated in Brisbane time" rule the rest of the site applies. If the target isn't published yet, replace the link with its own plain-text contents so no dead or premature link ships in the built page, and log a per-source-file warning listing which link targets got downgraded so the change is visible in build output. The link is expected to become live again automatically on a later scheduled rebuild once its target's publish date arrives.
