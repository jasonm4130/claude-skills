Beyond raw classification accuracy, the project wants to report how well-calibrated the fine-tuned model's confidence scores are, and to be able to correct them post-hoc. Add a calibration.py module under src/formrecap_lora/eval/ implementing post-hoc temperature scaling: an apply_temperature function that rescales a batch of logits by a temperature T and returns softmax probabilities (implemented numerically stably), a fit_temperature function that finds the temperature minimizing negative log-likelihood on a held-out set of logits and true labels via scipy.optimize.minimize_scalar over a sane bounded search range, and a calibrate_and_persist convenience function that fits the temperature and writes the result to a JSON file. Add scipy as a project dependency. Include unit tests verifying that T=1.0 is the identity transform, that higher temperature softens (flattens) the probability distribution, and that fitting recovers a temperature near 1.0 for a well-calibrated synthetic dataset and greater than 1.0 for an overconfident one.
