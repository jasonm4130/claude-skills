Synthetic training examples generated for the form-abandonment classifier can contain exact and near-duplicate records, which would bias the model if left in the training set. Add a dedupe.py module under src/formrecap_lora/data/ with two pieces: dedupe_exact, which removes records whose events string is byte-for-byte identical to one already seen, keeping the first occurrence and preserving relative order of the rest; and is_near_duplicate, which takes two embedding vectors and a similarity threshold (defaulting to 0.95) and reports whether their cosine similarity meets or exceeds that threshold, guarding against division by zero when either vector has zero magnitude. Include unit tests covering exact-duplicate removal, an empty input list, an all-unique pass-through case, identical embeddings, orthogonal embeddings, and a near-threshold case that should fall just under the cutoff.
