The PDF-to-markdown conversion step feeds every rulebook PDF through OCR by default, which wastes minutes per file on documents that already have a real embedded text layer. Disable OCR for the default conversion path while keeping table-structure detection on, reserving OCR for a separate escalation path for genuinely scanned files. Separately, the markdown-cleaning pass that collapses letter-spaced capitalized runs (e.g. author credits) assumes exactly one space between letters, but the converter actually emits a variable number of spaces; widen the pattern to match runs of one-or-more spaces. Also unescape HTML entities the converter emits and strip HTML image-placeholder comments before paragraph-grouping runs, so they don't get shredded into noise, then collapse any resulting runs of blank lines.
